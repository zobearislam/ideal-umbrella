# Ideal Umbrella

Browser-based interstellar trading, exploration, and empire-building simulator.

Fly ships in a 3D solar system, manage cargo and reputation, accept missions, run a transport company, and expand across star systems — from industrial resources all the way to omniversal and creator-tier realities.

## Quick start

```bash
npx serve .
# or
npm start
```

Then open http://localhost:3000

## Main pages

- `index.html` — 3D Simulator (fly, dock, trade, craft, complete missions)
- `missions.html` — Mission Board
- `transport.html` — Transport Company (fleet, contracts, journeys)
- `galaxy.html` — Galaxy Map
- `ui/company.html`, `ui/diplomacy.html`, `ui/finance.html` — additional management UIs

## Features

- Full solar system with planets and moons
- Shared game state across pages (inventory, credits, missions, ships)
- Massive resource economy (425+ resources), crafting, factions (116+), and reputation
- 165+ ship types from cargo haulers to Absolute Transcendent Emperors
- 235+ mission templates spanning hauling, combat, exploration, and diplomacy
- Transport contracts and NPC companies
- Local saves (optional Supabase cloud saves)
- Content expansions up to Transcendent Reality / Creator Tier (v1.5)

See CHANGELOG.md and CONTENT_EXPANSION.md for full content expansion history.
