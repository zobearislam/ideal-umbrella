# Ideal Umbrella

Browser-based interstellar trading, exploration, and empire-building simulator.

Fly ships in a 3D solar system, manage cargo and reputation, accept missions, run a transport company, and expand across star systems — from industrial resources all the way to omniversal, creator-tier, meta-existence, post-meta absolute beyond absolute, and beyond-absolute meta-existence realities.

## Quick start

```bash
npx serve .
# or
npm start
```

Then open http://localhost:3000

## Main pages

- `index.html` — 3D Simulator (fly, dock, trade, craft, complete missions)
- `missions.html` — Mission Board
- `transport.html` — Transport Company (fleet, contracts, journeys)
- `galaxy.html` — Galaxy Map
- `ui/company.html`, `ui/diplomacy.html`, `ui/finance.html` — additional management UIs

## Features

- Full solar system with planets and moons
- Shared game state across pages (inventory, credits, missions, ships)
- Massive resource economy (535+ resources), crafting, factions (149+), and reputation
- 212+ ship types from cargo haulers to Absolute Beyond Transcendent Emperors
- 307+ mission templates spanning hauling, combat, exploration, and diplomacy
- Transport contracts and NPC companies
- Local saves (optional Supabase cloud saves)
- Content expansions up to Post-Meta Absolute / Beyond Absolute Beyond / Source-Before-Source Tier (v1.7)

See CHANGELOG.md and CONTENT_EXPANSION.md for full content expansion history.
