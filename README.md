# Ideal Umbrella

Browser-based interstellar trading, exploration, and empire-building simulator.

Fly ships in a 3D solar system, manage cargo and reputation, accept missions, run a transport company, and expand across star systems — from industrial resources all the way to omniversal, creator-tier, meta-existence, post-meta absolute beyond absolute, absolute-beyond-beyond, absolute-beyond-beyond-beyond, and beyond-absolute meta-existence realities.

## Quick start

```bash
npx serve .
# or
npm start
```

Then open http://localhost:3000

## Main pages

- `index.html` — 3D Simulator (fly, dock, trade, craft, complete missions)
- `missions.html` — Mission Board
- `transport.html` — Transport Company (fleet, contracts, journeys)
- `galaxy.html` — Galaxy Map
- `ui/company.html`, `ui/diplomacy.html`, `ui/finance.html` — additional management UIs

## Features

- Full solar system with planets and moons
- Shared game state across pages (inventory, credits, missions, ships)
- Massive resource economy (770+ resources), crafting, factions (225+), and reputation
- 320+ ship types from cargo haulers to Absolute Beyond Beyond Beyond Emperors and Absolute Final Beyond Form
- 487+ mission templates spanning hauling, combat, exploration, and diplomacy
- Transport contracts and NPC companies
- Local saves (optional Supabase cloud saves)
- Content expansions up to Absolute Beyond Beyond Beyond Beyond / Source of Source of Source of Source of Source / Meta-Meta-Meta-Absolute-Beyond Tier (v2.0)
