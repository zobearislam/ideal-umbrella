# Changelog

## Expanded Content Update

- Added full solar system (Mercury–Neptune) + major moons (Luna, Phobos, Deimos, Galilean moons, Titan, Enceladus, Triton, etc.)
- Expanded star systems: Proxima Centauri, Tau Ceti, Epsilon Eridani, TRAPPIST-1, Barnard's Star
- New resources, crafting recipes, and ship types (Scout, Interceptor, Mining Rig, Liner, Capital, etc.)
- Mission board with 10 starter missions (delivery, combat, diplomacy, exploration)
- Updated transport prototype with more contracts, systems, and ship types
- Shared data files (`js/data/resources.js`, `js/data/missions.js`) and expanded `universe.js`
- New navigation links on the main simulator to Missions, Company, and Diplomacy pages
- Improved README documenting all new features

Previous content (simulator stub, transport prototype, galaxy map, company/diplomacy UIs, economy/IAG) remains and is now better integrated.
